# ADR 0002. JWT через Spring Security и Nimbus

**Статус:** принято
**Дата:** 2026-11-08

## Контекст

Нужны выпуск и проверка токенов, роли в claim, отзыв токена при выходе. Ручная реализация фильтра
требует обработки исключений в каждом запросе и легко расходится со стандартом OAuth 2.0.

## Решение

Использовать `spring-boot-starter-oauth2-resource-server`: `NimbusJwtEncoder` для выпуска,
`NimbusJwtDecoder` для проверки, симметричный ключ HS256. Отзыв реализован как
`OAuth2TokenValidator`, который обращается к списку отозванных `jti`. Роли читаются из claim `role`
через `JwtGrantedAuthoritiesConverter`.

## Последствия

- Плюс: 401 и обработка битых токенов — ответственность Spring Security, а не прикладного кода.
- Плюс: токен можно проверить без похода в базу, отзыв работает как быстрый фильтр.
- Минус: симметричный ключ требует общего секрета между инстансами; для внешних потребителей
  понадобится переход на RS256/JWKS.
- Минус: список отозванных токенов живёт до истечения TTL, значит нужен контроль lifetimes.

## Альтернативы

- Ручной фильтр на JJWT — больше кода и своих ошибок в обработке исключений.
- Непрозрачные сессии в Redis — проще отзыв, но теряется stateless-масштабирование.
