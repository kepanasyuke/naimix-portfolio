# ADR 0005. ИИ-фичи без внешних провайдеров

**Статус:** принято
**Дата:** 2026-11-08

## Контекст

Портфолио должно демонстрировать работу с ИИ, но не может зависеть от платных ключей, сетевых вызовов
и нестабильных ответов: демо должно работать офлайн и воспроизводимо.

## Решение

Две независимые фичи:

1. `matching-service` — собственная реализация TF-IDF по каталогу профилей и косинусная близость.
   Индекс строится при старте, запрос векторизуется тем же словарём.
2. `ai-assistant-service` — генерация текста через интерфейс `GenerationProvider`. Реализация по
   умолчанию — детерминированный шаблонный движок; внешняя LLM подключается новой реализацией
   интерфейса без изменения контроллеров.

Квота клиента считается скользящим окном в памяти, при превышении возвращается 429 с `Retry-After`.

## Последствия

- Плюс: воспроизводимость и предсказуемость — одинаковый вход даёт одинаковый выход.
- Плюс: точка расширения для реальной модели уже выделена и покрыта контрактом.
- Минус: качество текста ограничено шаблонами; это осознанный компромисс демо-режима.
- Минус: индекс TF-IDF живёт в памяти процесса, при горизонтальном масштабировании каталог должен
  переехать в общее хранилище.

## Альтернативы

- Внешний LLM API — требует ключей, денег и сети, ломает офлайн-демо.
- Локальная модель на ONNX — тяжёлая зависимость для портфолио.
